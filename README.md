# ЛФП — Семейный бюджет

PWA открывает рабочее приложение Google Apps Script. Код бюджета, синхронизация
с Дзен-мани и финансовые данные остаются в Apps Script и Google Таблице.

Основной адрес: https://ndinar1982.github.io/

Адрес https://ndinar1982.github.io/pwa-gas/ также работает для ранее установленных PWA.
Оба адреса открывают одно приложение.

При первом открытии вставьте адрес рабочего веб-приложения Apps Script, который
заканчивается на /exec. Он сохраняется в браузере этого устройства. Изменить его
можно через меню PWA → «Изменить адрес Apps Script».

## Исходники и публикация

- pwa-gas-src/ — оболочка, её значки, сборка и проверки.
- .github/workflows/ — проверка изменений и публикация через GitHub Actions.

Сборка использует только файлы этого репозитория. Публикуются оболочка и значки
по двум установленным адресам. Номер внутренней сборки не показывается в интерфейсе.

## Локальная проверка

Нужен Node.js 22 или новее. Из корня репозитория:

    node pwa-gas-src/test.mjs
    node pwa-gas-src/build-root.mjs _site
    node pwa-gas-src/test.mjs _site/pwa-gas
    node pwa-gas-src/test-root.mjs _site

Результат сборки находится в _site/. GitHub Pages настроен на источник GitHub Actions.
