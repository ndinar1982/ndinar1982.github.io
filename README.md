# ЛФП — PWA v9.69

Основной адрес: https://ndinar1982.github.io/

GitHub Pages публикует устанавливаемую оболочку семейного бюджета. Рабочий
`Index.html` целиком находится в Google Apps Script вместе с `Code.gs` и `Zen.gs`.
Оболочка открывает Web App `/exec` в iframe и сохраняет только выбранный адрес
в браузере устройства. Сохранённый адрес и вход в Apps Script при очистке не меняются.

## Текущая структура

- `pwa-gas-src/` — оболочка, manifest, Service Worker, сборка и проверки.
- `.github/workflows/publish-lfp.yml` — публикация GitHub Pages.
- `.github/workflows/check-pwa-gas.yml` — проверка изменений перед публикацией.
- `lfp-about.html`, `lfp-privacy.html` — действующие информационные страницы.
- Корневые `index.html` и `health.html` — прежние страницы проверки доступности;
  сохранены для совместимости с настроенной публикацией из ветки. Рабочую
  главную страницу формирует `pwa-gas-src/build-root.mjs`.

Дополнительный адрес `/pwa-gas/` сохранён для уже установленных PWA.
Идентификаторы и области действия установленных приложений не изменены.
Номер 9.69 относится к оболочке PWA; финансовый код Apps Script этой очисткой
не обновляется.

## История и резерв

В версии 9.69 удалены неиспользуемые `pwa-preview-src/`, `pwa-local-src/`
и их отдельные проверки. Их исходники доступны в истории Git.
Резерв прежнего интерфейса v9.68 сохранён по адресу `/v968-direct/`.
Для него сборка пока получает 48 ранее опубликованных файлов Firebase;
рабочая оболочка не использует их как финансовый интерфейс.

Полные исходники и архивные ветки остаются в приватном репозитории `bdds`.
Apps Script, Google Таблица и резервные копии на Google Диске этой очисткой
не изменяются. Серверные файлы, токены и финансовые данные в этом публичном
репозитории не размещаются.

При каждой следующей правке номер версии повышается. Сравнение скорости
и варианты загрузки основного кода с GitHub завершены; текущий вариант —
полный Index в Apps Script.
