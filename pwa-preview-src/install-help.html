Как установить

Android, Chrome: открой тестовую PWA в Chrome через меню браузера → «Установить приложение». Если такой команды нет, проверь, не установлена ли уже тестовая PWA. На телефонах без Google Mobile Services Chrome может предложить только ярлык.

iPhone: открой страницу в Safari (или другом браузере с поддержкой этого действия) → «Поделиться» → «На экран Домой».

Windows, Chrome/Edge: используй значок установки справа в адресной строке либо меню → «Установить эту страницу как приложение».

Событие beforeinstallprompt не обязано появляться в Safari, на некоторых устройствах Android и после установки. Отсутствие этого события само по себе не означает ошибку manifest.

Ограничение авторизации

Тестовое PWA использует прежний защищённый Google OAuth из GitHub v9.68, поэтому может снова просить вход после истечения токена. Быстрая версия Apps Script с Google-сессией остаётся отдельно. Здесь проверяем именно установку, отдельное окно и запуск с иконки.

Эта диагностика ничего не отправляет на сервер и не считывает данные бюджета.
