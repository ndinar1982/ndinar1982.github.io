Политика конфиденциальности ЛФП

Редакция от 21 ноября 2026 года

ЛФП — частное приложение для ведения семейного бюджета, предназначенное для небольшого круга разрешённых пользователей.

Какие данные используются

  • Адрес электронной почты и подтверждение входа Google — для проверки доступа пользователя.
  • Записи семейного бюджета, включая суммы операций, планы, остатки, цели и настройки, — из Google Таблицы, выбранной для работы ЛФП.
  • Данные Google Sheets и Google Drive и вызовы Google Apps Script API — для чтения и изменения бюджетных записей в соответствии с действиями пользователя.
  • При отдельно включённой интеграции ZenMoney — данные финансовых операций, необходимые для синхронизации семейного бюджета.

Как используются и хранятся данные

Финансовые записи обрабатываются для расчётов, отображения бюджета и синхронизации с выбранной семейной Google Таблицей и связанными скриптами Google Apps Script. Статические файлы интерфейса размещаются на GitHub Pages; GitHub Pages не используется как основное хранилище семейной таблицы.

В текущей версии Google OAuth access token может временно сохраняться в хранилище сессии браузера для выполнения запросов. Данные и авторизация также обрабатываются инфраструктурой Google в соответствии с настройками аккаунтов и сервисов. Как и другие веб-приложения, ЛФП может использовать локальные технические данные браузера, необходимые для работы интерфейса.

Передача и использование данных

Данные используются только для работы семейного бюджета и подключённых пользователем интеграций. Они не продаются, не используются для таргетированной рекламы и не публикуются на общедоступных страницах приложения. При использовании Google и ZenMoney данные передаются соответствующим сервисам только в пределах необходимых функций.

Управление доступом и удаление

Пользователь может выйти из ЛФП и отозвать доступ приложения в настройках аккаунта Google. Для удаления бюджетных записей владелец таблицы может управлять своей Google Таблицей и настройками связанного Apps Script. Отзыв OAuth-разрешений сам по себе не удаляет ранее сохранённые в таблице записи.

Контакты

По вопросам обработки данных обращайтесь по адресу поддержки приложения, указанному на экране согласия Google OAuth.
