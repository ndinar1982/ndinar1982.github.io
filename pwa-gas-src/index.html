Семейный бюджет

ЛФП · PWA

Эта PWA открывает существующий рабочий бюджет из Google Apps Script, а не создаёт новую пустую базу.

Адрес берётся в Apps Script → «Управление развёртываниями» → наше новое «Веб-приложение». Вставь его здесь один раз: адрес сохранится только в браузере этого устройства. Не используй адрес API Executable.

Доступ к финансам по-прежнему контролирует Google Apps Script. Отдельного входа Google на этой странице нет.

ЛФП · PWA

Открыт защищённый Google Apps Script внутри PWA. Платформа GitHub не читает и не сохраняет финансовые данные.

Если окно пустое или требует повторного входа, открой бюджет напрямую. Встроенный Google-сеанс может блокироваться политикой браузера.

Если бюджет не загрузился внутри окна, открой его напрямую.
